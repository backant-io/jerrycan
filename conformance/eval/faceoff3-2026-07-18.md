## Why they still break — the taxonomy moved up a layer
**Zero runtime bugs.** Breakage now lives in (a) generated-TEST truthfulness
and (b) missing contract surface:

1. **Tenancy trap (top severity, #78):** the tenant guard's membership query
   has no tenant filter (scaffold.rs:79); JL0006 never inspects the scope arg;
   no nested-creator isolation tests — a cross-tenant leak passes every gate.
   Trap-shaped (stubs 500; docs pattern mis-scopes, doesn't leak) but the
   natural nested-route implementation leaks.
2. **Per-user scoping has no backstop (#79):** isolation tests + JL0006 are
   tenancy-gated; JC0540 pushes per-user apps out of tenancy → leak with
   check green.
3. **Contract gap, 10/10 demand (#80):** no length/range field constraints —
   the single most repeated hand-work across all 30 eval builds.
4. **Mount blindness, double-sighted (#81, #82):** testgen ships literal
   `{x_id}` in mounted-subroute test URLs; path-FK trimming ignores mounts.
5. **Extensions without contract surface (#83):** rate limiting works at
   runtime but has no design key, pub(crate) middleware, and wiring
   permanently trips JL0003; middleware docs overclaim defaults.
6. Harness truthfulness (#84), generator polish batch (#85), docs batch (#86).

## Verdict
The contract layer is now solid — three fix waves each validated by fresh
cold-start agents, on crates the agents installed themselves. The remaining
failure surface is narrower and specific: make the generated tests as honest
as the runtime (mount resolution, harness wiring), close the two scoping
backstop gaps (#78/#79 — the only security-shaped items), and give the
contract the length/range surface every single app has asked for.
