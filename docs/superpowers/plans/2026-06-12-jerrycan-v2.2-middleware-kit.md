# jerrycan v2.2 — Middleware Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v2 spec's middleware kit (`docs/superpowers/specs/2026-06-11-jerrycan-v2-design.md` §v2.2): **CORS in jerrycan-core** (origin allowlist, credentials-safe — refuses `*` with credentials, preflight/OPTIONS handling) and **rate limiting as an extension** (fixed-window, in-memory store default + Redis store behind a feature, identity-aware partition key api-key→user→IP, `429 JC0429`, OPTIONS exempt).

**Architecture:** CORS is a *pre-routing* concern in core, NOT a `Middleware` — a preflight `OPTIONS` to a method-mismatched route is rejected `405` in `route_policy` before any middleware runs, so preflight is intercepted at the top of `route_policy` (204 short-circuit via the existing `Policy::Reject` seam) and actual-response headers are decorated at the dispatch exit AND the reject path. Rate limiting ships as a new optional crate `jerrycan-ratelimit` that registers via the existing `Extension` trait (a `Middleware` + a provided store + an `on_serve` sweeper) — exactly the `jerrycan-observe` shape. A small core change threads the socket peer address into `RequestCtx` to feed the IP partition tier. `JC0429` is added to core's error registry. Time comes from the injectable `Clock` so fixed windows are deterministic under `TestApp::clock().advance()`.

**Tech Stack:** Rust (MSRV 1.88), hyper 1 / http 1, the existing `Clock`/`Extension`/`Middleware`/`Policy` substrate, `redis` 0.27 (tokio + rustls, behind a feature), std `HashMap`/`Mutex` for the in-memory store.

**Branch:** `v2.2-middleware-kit` off `main`.

**Decisions taken (reversible pre-publish — flag in final report):**
- Rate-limit crate name: **`jerrycan-ratelimit`** (not among the 7 reserved crates.io names — a reservation is needed before 0.2.0 publish, which is deferred until the full v2 ladder lands; renaming before publish is trivial).
- The **Redis store ships now** behind a `rate-limit-redis` feature (the spec lists it as a v2.2 deliverable). Its runtime path is validated by an `#[ignore]`d integration test against a local Redis; CI exercises it for compile/lint/audit/deny under `--all-features`.

**Explicitly NOT in this phase (scope fence):**
- No design-contract or generator changes. `design-schema.json` (`additionalProperties:false`) and `design.rs` (`deny_unknown_fields`) stay as-is — a `cors`/`rate_limit` design key must still be REJECTED. CORS/rate-limit are `main.rs` hand-wiring, outside the tool-owned regeneration surface (confirmed by recon: zero hits across questions/genroute/testgen/scaffold/mounting).
- No `ApiKey` guard extractor / `require_scope` (that's v2.4) — the api-key partition tier reads a configurable raw header, it does not depend on a framework ApiKey type.
- No per-route CORS or per-route rate-limit (no per-route middleware substrate exists); scoping is app-level.
- No `kolli-slice` / conformance design changes; no testgen golden-output changes.

```rust
//! CORS (spec §v2.2). Lives in core because preflight must be answered BEFORE
//! routing (an `OPTIONS` to a method-mismatched route is rejected 405 before
//! any middleware runs), so CORS is a pre-routing + response-decoration concern
//! integrated into `route_policy`/dispatch — not a `Middleware`.

use std::time::Duration;

/// Which origins may make cross-origin requests.
#[derive(Clone, Debug)]
pub enum CorsOrigins {
    /// Any origin (`Access-Control-Allow-Origin: *`). Invalid with credentials —
    /// `App::build` refuses the combination.
    Any,
    /// An exact-match allowlist of origin strings (scheme + host + optional port).
    List(Vec<String>),
}

impl CorsOrigins {
    pub fn any() -> Self {
        Self::Any
    }
    pub fn list<I, S>(origins: I) -> Self
    where
        I: IntoIterator<Item = S>,
        S: Into<String>,
    {
        Self::List(origins.into_iter().map(Into::into).collect())
    }
}

/// CORS policy. Build with `CorsConfig::new(origins)` then chain options; install
/// with `App::cors(config)`.
#[derive(Clone, Debug)]
pub struct CorsConfig {
    origins: CorsOrigins,
    methods: Vec<http::Method>,        // None set => reflect the route's real methods on preflight
    headers: Vec<String>,              // empty => reflect Access-Control-Request-Headers
    expose: Vec<String>,
    allow_credentials: bool,
    max_age: Option<Duration>,
}

impl CorsConfig {
    pub fn new(origins: CorsOrigins) -> Self {
        Self {
            origins,
            methods: Vec::new(),
            headers: Vec::new(),
            expose: Vec::new(),
            allow_credentials: false,
            max_age: None,
        }
    }
    pub fn allow_credentials(mut self, yes: bool) -> Self { self.allow_credentials = yes; self }
    pub fn max_age(mut self, d: Duration) -> Self { self.max_age = Some(d); self }
    pub fn allow_headers<I: IntoIterator<Item = S>, S: Into<String>>(mut self, h: I) -> Self {
        self.headers = h.into_iter().map(Into::into).collect();
        self
    }
    pub fn expose_headers<I: IntoIterator<Item = S>, S: Into<String>>(mut self, h: I) -> Self {
        self.expose = h.into_iter().map(Into::into).collect();
        self
    }

    pub fn allow_credentials_enabled(&self) -> bool { self.allow_credentials }

    /// True if `origin` is permitted. `Any` matches everything; `List` is exact.
    pub fn allows_origin(&self, origin: &str) -> bool {
        match &self.origins {
            CorsOrigins::Any => true,
            CorsOrigins::List(list) => list.iter().any(|o| o == origin),
        }
    }

    /// Validate at build time: `*` + credentials is forbidden by the Fetch spec
    /// and is a footgun, so it is a build error, not a runtime surprise.
    pub(crate) fn validate(&self) -> crate::Result<()> {
        if self.allow_credentials && matches!(self.origins, CorsOrigins::Any) {
            return Err(crate::Error::internal(
                "CORS misconfiguration: allow_credentials(true) cannot be combined with CorsOrigins::any() — list explicit origins",
            ));
        }
        Ok(())
    }

    // accessors used by Tasks 4-5
    pub(crate) fn methods(&self) -> &[http::Method] { &self.methods }
    pub(crate) fn headers(&self) -> &[String] { &self.headers }
    pub(crate) fn expose(&self) -> &[String] { &self.expose }
    pub(crate) fn max_age(&self) -> Option<Duration> { self.max_age }
    pub(crate) fn allow_credentials(&self) -> bool { self.allow_credentials }   // pub(crate) twin of the pub builder name? rename to avoid clash
}
```

NOTE for the implementer: the public builder method `allow_credentials(bool)` and a reader can't share the name — expose the reader as `allow_credentials_enabled()` publicly (used in tests) and keep a `pub(crate)` reader for Tasks 4-5; pick non-clashing names and keep them consistent. Adjust the test in Step 1 to the chosen reader name.

- [ ] **Step 4: preflight responder in `cors.rs`** — a pure function that builds the preflight `Response`:

```rust
use crate::response::{JcBody, Response};
use http::{HeaderValue, Method, StatusCode, header};

/// Build the CORS preflight 204 for an allowed origin. `allowed_methods` are the
/// route's real methods. Returns a bare 204 carrying ONLY CORS headers (no
/// security headers — `cache-control: no-store` would fight `max-age`).
pub(crate) fn preflight_response(
    config: &CorsConfig,
    origin: &str,
    request_headers: Option<&str>,
    allowed_methods: &[Method],
) -> Response {
    let mut r = http::Response::new(JcBody::empty());
    *r.status_mut() = StatusCode::NO_CONTENT;
    let h = r.headers_mut();
    // origin: echo the specific origin (never '*' when credentials); with Any + no
    // credentials, '*' is allowed but echoing is also fine and simpler/uniform.
    if let Ok(v) = HeaderValue::from_str(origin) {
        h.insert(header::ACCESS_CONTROL_ALLOW_ORIGIN, v);
        h.insert(header::VARY, HeaderValue::from_static("Origin"));
    }
    if config.allow_credentials() {
        h.insert(header::ACCESS_CONTROL_ALLOW_CREDENTIALS, HeaderValue::from_static("true"));
    }
    let methods = if config.methods().is_empty() { allowed_methods } else { config.methods() };
    if let Ok(v) = HeaderValue::from_str(&methods.iter().map(|m| m.as_str()).collect::<Vec<_>>().join(", ")) {
        h.insert(header::ACCESS_CONTROL_ALLOW_METHODS, v);
    }
    // headers: configured list, else reflect the request's Access-Control-Request-Headers
    let allow_headers = if config.headers().is_empty() {
        request_headers.map(str::to_string)
    } else {
        Some(config.headers().join(", "))
    };
    if let Some(hdrs) = allow_headers {
        if let Ok(v) = HeaderValue::from_str(&hdrs) {
            h.insert(header::ACCESS_CONTROL_ALLOW_HEADERS, v);
        }
    }
    if let Some(age) = config.max_age() {
        if let Ok(v) = HeaderValue::from_str(&age.as_secs().to_string()) {
            h.insert(header::ACCESS_CONTROL_MAX_AGE, v);
        }
    }
    r
}

/// Is this request a CORS preflight? (OPTIONS + Origin + Access-Control-Request-Method)
pub(crate) fn is_preflight(parts: &http::request::Parts) -> bool {
    parts.method == Method::OPTIONS
        && parts.headers.contains_key(header::ORIGIN)
        && parts.headers.contains_key(header::ACCESS_CONTROL_REQUEST_METHOD)
}

/// origin. Insert-if-absent so handler-set values win; APPEND `Vary: Origin`
/// (don't clobber a content-negotiation Vary). No-op for a same-origin request
/// (no Origin) or a disallowed origin.
pub(crate) fn apply_cors(res: &mut Response, parts: &http::request::Parts, config: &CorsConfig) {
    let Some(origin) = parts.headers.get(header::ORIGIN).and_then(|v| v.to_str().ok()) else { return };
    if !config.allows_origin(origin) { return; }
    let Ok(origin_val) = HeaderValue::from_str(origin) else { return };
    let h = res.headers_mut();
    if !h.contains_key(header::ACCESS_CONTROL_ALLOW_ORIGIN) {
        h.insert(header::ACCESS_CONTROL_ALLOW_ORIGIN, origin_val);
    }
    if config.allow_credentials() && !h.contains_key(header::ACCESS_CONTROL_ALLOW_CREDENTIALS) {
        h.insert(header::ACCESS_CONTROL_ALLOW_CREDENTIALS, HeaderValue::from_static("true"));
    }
    if !config.expose().is_empty() && !h.contains_key(header::ACCESS_CONTROL_EXPOSE_HEADERS) {
        if let Ok(v) = HeaderValue::from_str(&config.expose().join(", ")) {
            h.insert(header::ACCESS_CONTROL_EXPOSE_HEADERS, v);
        }
    }
    // Vary: Origin — append unless already present (caches must not serve wrong-origin).
    let has_origin_vary = h.get_all(header::VARY).iter().any(|v| v.to_str().map(|s| s.eq_ignore_ascii_case("origin") || s.split(',').any(|p| p.trim().eq_ignore_ascii_case("origin"))).unwrap_or(false));
    if !has_origin_vary {
        h.append(header::VARY, HeaderValue::from_static("Origin"));
    }
}

//! The rate-limit store: a fixed-window check-and-increment keyed by an opaque
//! partition string. Time is supplied by the caller (`now`) so windows are a
//! pure function of the injected Clock and TestApp::clock().advance() rolls them.

use std::time::{Duration, SystemTime};

/// The result of one `hit`.
#[derive(Clone, Copy, Debug)]
pub struct Outcome {
    /// Whether this request is under the limit.
    pub allowed: bool,
    /// Requests left in the current window (0 when blocked).
    pub remaining: u32,
    /// Time until the current window ends (the Retry-After value when blocked).
    pub retry_after: Duration,
}

/// A fixed-window rate-limit store. Object-safe so the App holds `Arc<dyn ...>`.
pub trait RateLimitStore: Send + Sync + 'static {
    /// Record one request against `key` and report whether it is allowed. The
    /// window is `[window_start, window_start + window)` derived from `now`.
    fn hit<'a>(
        &'a self,
        key: &'a str,
        window: Duration,
        limit: u32,
        now: SystemTime,
    ) -> std::pin::Pin<Box<dyn std::future::Future<Output = jerrycan_core::Result<Outcome>> + Send + 'a>>;
}

/// Window id = floor(epoch_ms / window_ms). A pure function of `now`.
fn window_bounds(now: SystemTime, window: Duration) -> (u64, Duration) {
    let ms = now.duration_since(SystemTime::UNIX_EPOCH).map(|d| d.as_millis() as u64).unwrap_or(0);
    let wms = window.as_millis().max(1) as u64;
    let id = ms / wms;
    let elapsed = ms % wms;
    let retry_after = Duration::from_millis(wms - elapsed);
    (id, retry_after)
}

#[derive(Default)]
pub struct InMemoryStore {
    inner: std::sync::Mutex<std::collections::HashMap<String, (u64, u32)>>, // key -> (window_id, count)
}

impl InMemoryStore {
    pub fn new() -> Self { Self::default() }

    /// Drop keys whose window has already passed (idle eviction). Called by the
    /// sweeper and unit tests; pure given `now`.
    pub fn prune_expired(&self, now: SystemTime) {
        let (current, _) = window_bounds(now, Duration::from_millis(1)); // not used directly; see below
        let _ = current;
        // implement: lock, retain entries whose window_id corresponds to a window
        // not strictly older than the current one for THEIR window size. Since the
        // window size isn't stored per-key, store (window_id, count) keyed by the
        // window the middleware computed; prune drops entries whose window_id's end
        // (window_id+1)*window_ms <= now. SIMPLEST: store the absolute window_start
        // ms instead of id and prune entries with window_start + a max_window < now.
        // Implementer: choose a representation that makes prune correct for the
        // single global window size the limiter is configured with (pass the window
        // to prune, OR store window-end ms per entry). Keep the test above green.
    }

    #[cfg(test)]
    pub fn entry_count(&self) -> usize { self.inner.lock().unwrap().len() }
}

impl RateLimitStore for InMemoryStore {
    fn hit<'a>(&'a self, key: &'a str, window: Duration, limit: u32, now: SystemTime)
        -> std::pin::Pin<Box<dyn std::future::Future<Output = jerrycan_core::Result<Outcome>> + Send + 'a>>
    {
        Box::pin(async move {
            let (id, retry_after) = window_bounds(now, window);
            let mut map = self.inner.lock().unwrap();
            let entry = map.entry(key.to_string()).or_insert((id, 0));
            if entry.0 != id { *entry = (id, 0); } // rolled into a new window
            entry.1 += 1;
            let count = entry.1;
            let allowed = count <= limit;
            Ok(Outcome {
                allowed,
                remaining: limit.saturating_sub(count),
                retry_after,
            })
        })
    }
}

                            // Only the in-memory store needs pruning; downcast-or-skip.
                            // Keep generic: add a `prune(&self, now)` no-op default on the trait,
                            // overridden by InMemoryStore. Use REAL tokio time for the interval,
                            // the injected Clock only for the boundary `now`.
                            store.prune(clock.now());
                        }
                        _ = shutdown.changed() => break,
                    }
                }
            }
        })
    }
}
```

```rust
use crate::RateLimit;
use jerrycan_core::{Clock, Error, Middleware, MiddlewareFuture, Next, RequestCtx};
use jerrycan_core::response::IntoResponse;
use std::time::SystemTime;

pub(crate) struct RateLimitMw {
    cfg: RateLimit,
}

impl RateLimitMw {
    pub(crate) fn new(cfg: RateLimit) -> Self { Self { cfg } }

    /// api-key header → user-key closure → IP. First that yields a key wins; the
    /// tier prefix prevents cross-tier collisions. Returns None only if no tier
    /// produces anything (then the request is NOT limited — fail open).
    fn partition_key(&self, ctx: &RequestCtx) -> Option<String> {
        if let Some(v) = ctx.headers().get(&self.cfg.api_key_header).and_then(|v| v.to_str().ok()) {
            // hash so the raw secret is not held in the window map
            use std::hash::{Hash, Hasher};
            let mut h = std::collections::hash_map::DefaultHasher::new();
            v.hash(&mut h);
            return Some(format!("apikey:{:016x}", h.finish()));
        }
        if let Some(uk) = &self.cfg.user_key {
            if let Some(u) = uk(ctx) { return Some(format!("user:{u}")); }
        }
        let ip = if self.cfg.trust_forwarded_for {
            ctx.headers().get("x-forwarded-for")
                .and_then(|v| v.to_str().ok())
                .and_then(|s| s.split(',').next())
                .map(|s| s.trim().to_string())
        } else { None }
        .or_else(|| ctx.peer_addr().map(|a| a.ip().to_string()));
        ip.map(|ip| format!("ip:{ip}"))
    }
}

impl Middleware for RateLimitMw {
    fn handle<'a>(&'a self, ctx: &'a mut RequestCtx, next: Next<'a>) -> MiddlewareFuture<'a> {
        Box::pin(async move {
            // OPTIONS exempt (CORS preflight + any OPTIONS): never throttle.
            if ctx.method() == http::Method::OPTIONS {
                return next.run(&mut *ctx).await;
            }
            let Some(key) = self.partition_key(ctx) else {
                return next.run(&mut *ctx).await; // no identity → fail open
            };
            let now: SystemTime = match ctx.resolve::<Clock>().await {
                Ok(clock) => clock.now(),
                Err(_) => return next.run(&mut *ctx).await, // no clock → fail open
            };
            match self.cfg.store.hit(&key, self.cfg.window, self.cfg.limit, now).await {
                Ok(out) if out.allowed => next.run(&mut *ctx).await,
                Ok(out) => {
                    let mut resp = Error::too_many_requests().into_response();
                    let secs = out.retry_after.as_secs().max(1);
                    if let Ok(v) = http::HeaderValue::from_str(&secs.to_string()) {
                        resp.headers_mut().insert(http::header::RETRY_AFTER, v);
                    }
                    resp
                }
                Err(e) => e.into_response(), // store failure → surface (JC0500)
            }
        })
    }
}
```

Decisions baked in (note in commit/docs): **fail-open** when no identity or no clock (a misconfigured limiter must not break all traffic); the api-key value is **hashed** (non-crypto `DefaultHasher` — partitioning, not security; the raw secret is never stored); the **IP tier uses the raw socket peer by default**, `X-Forwarded-For` only when `trust_forwarded_for(true)` (spoofing note → threat model). Confirm `jerrycan_core::response::IntoResponse` and `Clock`/`Error` are reachable from the crate (they are re-exported at core lib root).

```rust
//! Redis-backed fixed-window store (behind `rate-limit-redis`). Each window is a
//! key `ratelimit:{partition}:{window_id}` incremented atomically with a TTL of
//! one window, so eviction is Redis's job (no sweeper needed).

use crate::store::{window_bounds, Outcome, RateLimitStore};
use std::time::{Duration, SystemTime};

const SCRIPT: &str = r#"
local c = redis.call('INCR', KEYS[1])
if c == 1 then redis.call('PEXPIRE', KEYS[1], ARGV[1]) end
return c
"#;

pub struct RedisStore {
    client: redis::Client,
}

impl RedisStore {
    /// Connect to `url` (e.g. `redis://127.0.0.1/`). Async work happens here so
    /// the Extension::register stays sync (mirrors Db::connect).
    pub async fn connect(url: &str) -> jerrycan_core::Result<Self> {
        let client = redis::Client::open(url)
            .map_err(|e| jerrycan_core::Error::internal(format!("redis: {e}")))?;
        // ping to fail fast on a bad url
        let mut conn = client.get_multiplexed_async_connection().await
            .map_err(|e| jerrycan_core::Error::internal(format!("redis connect: {e}")))?;
        redis::cmd("PING").query_async::<()>(&mut conn).await
            .map_err(|e| jerrycan_core::Error::internal(format!("redis ping: {e}")))?;
        Ok(Self { client })
    }
}

impl RateLimitStore for RedisStore {
    fn hit<'a>(&'a self, key: &'a str, window: Duration, limit: u32, now: SystemTime)
        -> std::pin::Pin<Box<dyn std::future::Future<Output = jerrycan_core::Result<Outcome>> + Send + 'a>>
    {
        Box::pin(async move {
            let (id, retry_after) = window_bounds(now, window);
            let redis_key = format!("ratelimit:{key}:{id}");
            let mut conn = self.client.get_multiplexed_async_connection().await
                .map_err(|e| jerrycan_core::Error::internal(format!("redis: {e}")))?;
            let count: u32 = redis::Script::new(SCRIPT)
                .key(redis_key)
                .arg(window.as_millis() as u64)
                .invoke_async(&mut conn).await
                .map_err(|e| jerrycan_core::Error::internal(format!("redis: {e}")))?;
            Ok(Outcome {
                allowed: count <= limit,
                remaining: limit.saturating_sub(count),
                retry_after,
            })
        })
    }
    // prune is the trait default no-op; Redis TTLs handle eviction.
}
```
