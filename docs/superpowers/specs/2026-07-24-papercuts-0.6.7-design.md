## A. #128 — scaffold output must be `cargo fmt`-clean for every app shape
0.5.2 (#120) fixed the `mod`-ordering half. Residual: heavier apps (openapi/jobs/postgres) emit long lines that `cargo fmt` rewraps, re-tripping **JL0003** (generated-file drift) once the agent implements stubs and `jerrycan check` reaches the lint:
- `main.rs`: the `.extend(... OpenApi::new(include_str!("../../../openapi.json")))` builder line.
- `migrations.rs`: long `postgres: include_str!("...")` path lines.
**Fix:** emit those lines **pre-wrapped exactly as `cargo fmt` formats them** (find the emitters in genroute/scaffold/mounting; wrap to match rustfmt's output) so a fresh scaffold of ANY shape passes `cargo fmt --check`. Verify by scaffolding an openapi+jobs+postgres app and running `cargo fmt --check` clean. Goldens for those shapes legitimately change to the wrapped form (intended); todo-api (no openapi/jobs) may be unaffected — update whatever legitimately changes.

## B. #141 — refuse an entity that collides with the generated membership table/type
When `tenancy` is present, an entity named `{Tenant}Member` (e.g. `ClubMember`) has default table `{tenant}_members` (`club_members`) — colliding with the generated membership table, AND (since #107) the generated `pub struct {Tenant}Member` row type. Today: clean `check`, then an opaque `table "club_members" already exists` mid-scaffold.
**Fix:** a new design-time error (next free JC code — verify highest in codes.rs, likely JC0553) raised from questions.rs when tenancy is present and an entity's table name equals `{tenant}_members` OR its name equals `{Tenant}Member` (the generated row type). Fail loud at `check` with a clear rename suggestion. Test: `Club` tenancy + `ClubMember` entity → the new code; a non-colliding entity → clean.

## C. #129 — drift tripwire: RESERVED_PRELUDE_IDENTS ⊇ the prelude's re-exports
`RESERVED_PRELUDE_IDENTS` (questions.rs, JC0546) is a hand-maintained mirror of `jerrycan_core::prelude` + `main`. If a future `pub use` is added to the prelude but not the set, an entity named after it silently reopens #114 (uncompilable app, E0659).
**Fix:** add an `embedded_sync`-style test that reads the prelude source (`jerrycan_core::prelude` — and `jerrycan_macros::main`) and asserts `RESERVED_PRELUDE_IDENTS` ⊇ every re-exported ident, so a drift fails CI. Test-only.

## D. #159 — MCP `jerrycan_gen_tests` optional module (mirror the 0.6.4 CLI)
0.6.4 made the CLI `jerrycan gen-tests` runnable without `--module` (bare = all modules + jobs). The MCP twin `jerrycan_gen_tests` still requires `module`.
**Fix:** make the MCP tool's `module` param optional (mirror the CLI's `Option<String>` → `gen_tests_all`); update `mcp-tools.json` (the tool schema — `module` no longer required); add an MCP-dispatch test for the module-less call. Keep the single-module MCP call byte-identical.
